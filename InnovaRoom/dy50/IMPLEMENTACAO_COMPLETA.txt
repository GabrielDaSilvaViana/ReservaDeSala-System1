🎯 FLUXO COMPLETO (Biometria + Micro Switch)

1. Usuário aproxima dedo no leitor DY50
2. Middleware DY50 chama: window.dy50_onFingerprintScanned("FB-12345")
3. JavaScript valida: POST /api/authenticate
4. Se autorizado: POST /api/solenoid/unlock (5000ms)
5. ESP32 ativa GPIO 33 (solenoide)
6. Solenoide estende e pressiona o micro switch
7. GPIO 32 vai de HIGH para LOW
8. ESP32 Log: "[SWITCH] Mudança detectada: DESTRANCADA (LOW)"
9. Browser polling consulta GET /api/solenoid/status a cada 800ms
10. UI atualiza: Botão muda para "Estado: destrancado" (verde)
11. Após 5000ms, ESP32 desativa GPIO 33
12. Solenoide retrai e libera o micro switch
13. GPIO 32 volta para HIGH
14. ESP32 Log: "[SWITCH] Mudança detectada: TRAVADA (HIGH)"
15. Browser detecta e UI volta para "Estado: travado" (vermelho)

🧪 COMO TESTAR

1. Compile e carregue solenoid_arduino.ino no ESP32
2. Verifique no Serial Monitor: deve aparecer "[SWITCH] Mudança detectada"
3. Reinicie servidor Node.js (server.js)
4. Abra navegador e carregue a página com dy50_integration.js
5. Abra console do navegador (F12) e procure por "[dy50] Falha..." (deve estar vazio)
6. Clique no botão "Testar leitura (fallback)" ou aproxime dedo no DY50
7. Observe:
   - Painel mostra: "Autorizado: [nome do usuário]"
   - Botão muda para: "Estado: destrancado" (verde)
   - Serial Monitor mostra: "[SWITCH] Mudança detectada: DESTRANCADA (LOW)"
8. Após 5 segundos:
   - Botão volta para: "Estado: travado" (vermelho)
   - Serial Monitor mostra: "[SWITCH] Mudança detectada: TRAVADA (HIGH)"
