🔄 NOVO COMPORTAMENTO

ANTES (modo legacy - fixo):
  1. Autoriza → Solenoide ativa
  2. 5 segundos passam
  3. Solenoide desativa automaticamente

AGORA (modo condicional - inteligente):
  1. Autoriza → Solenoide ativa
  2. Enquanto PRESSIONA o switch (GPIO 32 = LOW):
     └─ Solenoide MANTÉM ativa (não desativa)
  3. Ao LIBERAR o switch (GPIO 32 = HIGH):
     └─ Inicia countdown de 5 segundos
  4. Se PRESSIONAR novamente antes de 5s:
     └─ Reseta countdown (continua ativa)
  5. Se 5s passarem SEM pressão:
     └─ Solenoide desativa automaticamente

🔧 NOTAS TÉCNICAS

Variáveis críticas:
  • isControlledBySwitch (bool): Ativa/desativa modo de controle
  • switchReleaseTime (unsigned long): Marca quando switch foi liberado
  • RELEASE_COUNTDOWN_MS (5000): Tempo em ms para auto-trava

Estados possíveis:
  1. isControlledBySwitch = false: Modo legado (timeout fixo)
  2. isControlledBySwitch = true + switchReleaseTime = 0: Aguardando pressão
  3. isControlledBySwitch = true + switchReleaseTime > 0: Em countdown

Comportamento de pressionamento:
  • Se pressiona novamente antes de 5s: switchReleaseTime reseta para 0
  • Se 5s passarem: switchReleaseTime expira e solenoide desativa

🧪 COMO TESTAR

1. Compile e carregue o novo Arduino
2. Autorize uma digital (ou clique "Testar")
3. Observe Serial Monitor: "[SWITCH-CONTROL] Modo ativado"
4. Pressione o switch:
   - Serial: "[SWITCH] Mudança detectada: DESTRANCADA (LOW)"
   - Painel: "Destrancado (5s)" [NÃO decrementa enquanto pressiona]
5. Libere o switch:
   - Serial: "[SWITCH] Mudança detectada: TRAVADA (HIGH)"
   - Painel: "Destrancado (5s)" [AGORA decrementa: 5 → 4 → 3...]
6. Pressione de novo antes de terminar:
   - Countdown reseta
   - Painel volta para "Destrancado (5s)"
7. Espere 5s sem pressionar:
   - Serial: "[SWITCH-CONTROL] Countdown expirou..."
   - Painel: "Estado: travado"
