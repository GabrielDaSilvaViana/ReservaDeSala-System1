🔌 HARDWARE — Checklist de montagem

[ ] Compre: 1x Micro Switch (push button NO — normally open)
[ ] Compre: 1x Resistor 10kΩ
[ ] Identifique pinos do micro switch (COM, NO, NC)
[ ] Solde: Resistor 10kΩ entre +3.3V e GPIO 32 (pull-up)
[ ] Solde: Pino COM do switch para GND
[ ] Solde: Pino NO do switch para GPIO 32
[ ] Fixe mecanicamente o switch próximo à solenoide
   → Quando solenoide estende (destranca) → switch pressiona → GPIO 32 = LOW
   → Quando solenoide retrai (trava) → switch libera → GPIO 32 = HIGH (pull-up)

Teste com multímetro:
- GPIO 32 a GND = ~3.3V quando repouso (travada)
- GPIO 32 a GND = ~0V quando pressiona (destrancada)

---

⚙️ CÓDIGO — O que esperar

No Serial Monitor do ESP32 você verá:

[SWITCH] Mudança detectada: TRAVADA (HIGH)
[SWITCH] Mudança detectada: DESTRANCADA (LOW)

No painel de biometria (UI):
- Botão "Estado: travado/destrancado" atualiza a cada 800ms com a leitura real
- Mesmo se o comando do servidor falhar, a UI mostra o estado verdadeiro do switch

Na API:
GET /api/solenoid/status
Retorna: {"solenoid": {"state": "locked", "locked": true}}

⚡ DIAGNOSTICANDO PROBLEMAS

1. Switch não é lido no Serial Monitor
   → Verifique GPIO 32 no código do ESP32 (compatível com sua placa)
   → Teste se pino está em INPUT_PULLUP corretamente

2. Estado sempre mostra como "travado"
   → O switch está solto fisicamente? Aperte manualmente para testar
   → Resistor 10kΩ está conectado?

3. Painel não atualiza o estado
   → Abra o console do navegador (F12)
   → Veja logs de erro ao chamar /api/solenoid/status
   → ESP32 está online? Ping em http://[ESP32_IP]:80/health

4. Solenoide não funciona depois da mudança
   → Os endpoints /unlock e /lock ainda existem ✅
   → Código Arduino não foi quebrado, apenas adicionado
   → Verifique se GPIO 33 (SOLENOID_PIN) ainda funciona
