⏱️ TIMERS E DEBOUNCE

Arduino (Loop):
  ┌─────────────────────────────────────┐
  │ Cada 50ms (SWITCH_DEBOUNCE_MS):     │
  │   Lê GPIO 32                        │
  │   Se mudou: registra e imprime      │
  │ Cada ciclo:                         │
  │   Checa se solenoid expirou         │
  │   Se sim: desativa GPIO 33          │
  └─────────────────────────────────────┘

Browser (Polling):
  ┌─────────────────────────────────────┐
  │ Cada 800ms:                         │
  │   GET /api/solenoid/status          │
  │   Recebe {"locked": true/false}     │
  │   Atualiza UI se mudou              │
  └─────────────────────────────────────┘

API Response:
  ┌─────────────────────────────────────┐
  │ {                                   │
  │   "status": "ok",                   │
  │   "solenoid": {                     │
  │     "state": "locked",              │
  │     "locked": true,                 │
  │     "device": "esp32-solenoid",     │
  │     "lastCheck": "2026-10-05..."    │
  │   }                                 │
  │ }                                   │
  └─────────────────────────────────────┘

🎛️ RESUMO TÉCNICO

Componente          | Função                    | Segurança
────────────────────┼──────────────────────────┼─────────────────────
Micro Switch        | Detecta posição mecânica  | Fail-safe (pull-up)
Resistor 10kΩ       | Garante nível HIGH       | Evita oscilações
GPIO 32             | Lê estado do switch       | Input com debounce
GPIO 33             | Ativa solenoide          | Timeout automático
Debounce (50ms)     | Elimina falsas leituras  | Arduino-side
Polling (800ms)     | Sincroniza UI            | Não bloqueia
Timeout (5000ms)    | Auto-trava solenoide     | Segurança (sem comandos)
